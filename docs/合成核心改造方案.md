# 合成核心设计：简介 + 合成门槛 + 核心发射器

## 设计总览

核心成为游戏的「进度中枢」，三个作用层层递进：

1. **核心光环**（已上线）：全场发射器产出概率升一级；
2. **合成权限**（第一期已上线）：物品链分三档，高档合成需要核心等级；
3. **核心发射器**（第二期已上线）：核心本身变成发射器，点击产出各发射器链的链首材料；夜战掉落不再给链首材料；
4. **核心 = 基地核心建筑**（第三期已上线，见文末「六、第三期」）：棋盘与基地合并后，合成核心不再是棋盘道具，而是基地正中央那格核心建筑（cfgId=1）；点击核心格 = 发射棋子，长按 = 核心面板（等级/光环/档次/库存/升级）。

## 一、查看按钮 + 核心简介

- ~~InfoBar 的核心链道具「简介」按钮~~ → 第三期改为：选中核心格时 InfoBar 显示「核心 / 查看」两个按钮，长按核心格直接开核心面板。

  - 标题：合成核心；图标随当前等级；
  - 简介文案（i18n `core.intro.*`，zh+en）：外婆留下的装置、三个作用（光环/工坊/合成权限）、升级方式（夜战精英 Boss 掉神秘零件，两两合成）；
  - 动态状态行：当前核心等级、当前光环 %、当前可合成档次。

## 二、合成门槛（核心等级 = 物资档次）

### 分档（按 id 区间，写在 `MergeCoreConfig.ts`，不动 prop 数据）

- **普通档 tier 0**（基座即可）：10001~10028 工具系、20011~20029 净水/口粮/药品、30001~30054 拾荒/储物/钥匙/地图/线索/遗失物、40001~40056 种植系、50017~50035 猫鼠彩蛋链
- **钢铁档 tier 1**（需 60027 原型）：20030~20040 物资推车、20041~20058 废铁/防御材料、20065~20077 手册/技能、30067~30082 远征/武器/手办、50001~50016 机器人/废料、60001~60007 电源/充电桩
- **科技档 tier 2**（需 60029 二型）：20059~20064 无线电、30055~30066 遗物/终端、60008~60020 拆解器/超频器/芯片
- **豁免**：60021~60023 孤品功能道具、60024~60031 核心自身、70001+ 全部蓝图链（不卡建筑解锁）

### 判定

- `MergeCoreConfig.ts` 新增 `getItemTier(id)`（区间表）和 `getCoreTier(state)`（扫棋盘最高核心：无/基座=0，原型/TG-I=1，二型及以上=2）；
- `MergeSystem.ts:118` 合成条件处插入门槛检查：`getItemTier(nextId) > getCoreTier(state)` → 弹回 + toast「需要 {核心名} 才能合成这类物品」（i18n `toast.mergeNeedsCore`，复刻 :112-116 双蛛网提示模式）；
- **订单系统同步**：TaskSystem 订单候选链过滤掉未解锁档次（否则刷出合不了的订单），与 MERGE_LOOKAHEAD 同一处过滤；
- 黑市/宝箱产物不受限（拿到高级材料不违规，只是合不了）。

### 初始棋盘避坑（必须做）

初始棋盘里有钢铁/科技档物品：50003×2、50004（机器人，钢铁档）、20060（无线电，科技档）。开局会被门槛卡住，替换为普通档：
- 50003(1,2)→20011 净水、50003(2,6)→10012 维修工具、50004(3,6)→40001 花盆、20060(3,3)→20021 口粮；
- **实施时先 grep 新手任务链（task_newTask.json）和引导是否引用这 4 个 id**，有引用就同步调整；
- smoke 里初始棋盘断言（数量/封印分布）同步更新。

## 三、核心发射器（核心 = 发射器，第二期已实现）

### 设计要点（用户确认版）

- 只产出**发射器链的链首材料**（旧保温箱、小种子包、种子、工具箱把手等 16 种），消耗品/材料链产物仍走夜战掉落；
- 点击耗 **1 体力**（与其他发射器一致，体力是长期产出的天然限制）；
- 回满 CD 60~84 分钟（初版 10 分钟实测太快，发射器链几天就铺满），库存随等级 6→16 成长；
- 二型起小概率直接出 **L2 材料**，概率随等级提升（≈14% → 21% → 27%）；
- 核心自身产出也过光环（基座 5% 概率升一级），与 L2 池叠加形成正反馈。

### 夜战掉落去链首材料（zombie.json，已落地）

- 移除全部链首 id：20001 旧保温箱（普通/快速/飞行）、30001 旧车轮（坦克）、40011 小种子包、40027 种子（普通）、30019 钥匙（钻地）；
- 保留其余掉落（脏水/口粮/维修材料/手提包/精英 Boss 保底 60024 等）不动。

### 平衡兜底

- 冷藏箱（20001）剧情 beat 照发，不断水；收集站 outputPool 不动；
- 升级节奏：60024 精英×1/Boss×2 → 约第 8~10 天到原型（开钢铁档）、第 14 天左右到二型（开科技档）。

## 六、第三期：合成核心 = 基地核心建筑

### 背景

棋盘与基地合并后，基地 13×13 就是合成场，中央 (6,6) 是基地核心建筑（cfgId=1，1000 血）。
再往棋盘上摆一个「核心基座道具」既占格又概念重复，因此把合成核心的三作用整体挂到核心建筑上。

### 实现要点

| 主题 | 做法 |
|---|---|
| 等级载体 | `IBuilding.level` 1~6（仅 kind=core），数值/图标/名称仍取 `prop_prop.json` 的 60026~60031（`CoreConfig.CORE_LEVEL_PROP`），养成曲线 1:1 不变 |
| 配置层 | 新增 `src/core/config/CoreConfig.ts`：库存/CD/光环/合成档次/产出池/升级消耗，全部按核心等级查表 |
| 逻辑层 | 新增 `src/core/systems/CoreSystem.ts`：`clickSpawn`（发射）、`upgrade`（升级）、`tick`（冷却回满）、`skipCd`（钻石跳 CD）、`materialValue`（材料当量统计/扣除） |
| 发射状态 | 库存/CD 存在核心建筑上（`IBuilding.times/cd/cdSum`），由 `SpawnSystem` 的 500ms 心跳调用 `CoreSystem.tick` 回满 |
| 交互 | 单击核心格 = 选中 → 再点发射（连发）；**长按 480ms = 核心面板**；2D/3D 两条输入链路同一判定树（`handleCellTap` / `IBase3DHost.onCellLongPress`） |
| 面板 | `CoreIntroPanel` 扩成核心面板：等级、库存、冷却、光环、合成档次、升级消耗与按钮、修复、查看产出（`SpawnerProductsPanel.openCore` 按核心等级展示产出池） |
| 升级消耗 | 夜战掉落的 60024 神秘零件 = 1 当量、60025 核心残片 = 2 当量；升到 Lv2/3/4/5/6 分别需 8/16/32/64/128 当量，材料从棋盘与背包扣除（低当量优先） |
| 新手引导 | `state.coreClickCount` 记录核心点击次数，前两发走 `CORE_GUIDE_HANDLES = [10001, 10001]`（不吃光环），替代原核心道具的 `clickPropId`；引导横幅改为检测「产出源 = 核心格」 |
| 旧档兼容 | 不升 SAVE_VERSION：读档时 `StorageSystem.migrateMergeCoreToBase` 扫描棋盘/背包/卡片里最高级核心道具（60026~60031）→ 折算成核心等级并移除该道具，60024/60025 材料保留 |
| 配置表调整 | `prop_new.json` 删掉 (6,9) 的核心基座摆放；`60025.blessId` 改 0（核心残片成为链尾，不再合出已退休的核心道具）；`PropConfig.isRetiredCoreProp` 把 60026~60031 排出「链首来源」判定 |
| 剧情 | 新增 `coreLevel` 触发器（等级 >= value），第 4 章北岸电台 beat 由 `item:60026` 改为 `coreLevel:2`（首次升级核心时触发） |

### 测试

`scripts/smoke.ts` 新增：核心库存/CD 逐级表、产出池逐级解锁、点击发射（耗体力/扣库存/进冷却/冷却回满/体力不足/棋盘满）、升级（当量统计、材料不足失败、棋盘+背包扣除、满级、光环档次即时生效）、钻石跳 CD、旧档折算迁移；
原有「核心基座」相关断言全部改为按核心等级断言（2968 项通过）。
