# Blender 参考图 100% 还原工艺 SOP

## 目标

以说明书、效果图和游戏内预览为唯一依据，制作可交付的 Blender/GLB 模型。这里的“100%还原”指模型结构、部件位置、比例、颜色分区和最终镜头与参考图一致；如果参考图没有提供真实尺寸，必须先建立可复核的比例假设并记录。

## 1. 输入资料与冻结规则

每个资产建立一个独立目录，至少包含：

- 原始效果图（不得二次压缩）
- 拼装说明书或零件清单
- 游戏中目标格子尺寸
- 参考图中的正面、侧面、俯视关系
- 资产 ID、文件名和版本号

开始建模后冻结参考图版本。任何比例或颜色变化必须增加版本号，不能覆盖参考资料。

## 2. 坐标与比例

- Blender 使用原生 Z-up：X 为左右，Y 为前后，Z 为高度。
- GLB 导出时不做整体旋转，不在 Three.js 中补 X/Z 轴旋转。
- 先确定一个基准颗粒：标准 1x1 颗粒宽度为 `u`。
- 所有尺寸写成 `u` 的整数或半整数倍；底座、墙体、屋顶和设备都从该网格派生。
- 模型原点放在底座中心，底座最低点为 Z=0。
- 建筑必须能放入正式棋盘格，底座边界不得超出目标格子碰撞范围。

## 3. 建模顺序

严格按以下顺序制作并保存阶段文件：

1. 底座：土层、边框、地砖、草地颗粒。
2. 地基：灰色基座、台阶、围栏和装饰边。
3. 主体：按说明书逐层堆叠墙体，保留真实砖块接缝。
4. 功能部件：门、窗、控制台、空调、储罐、风机或太阳能板。
5. 标识部件：红十字、警示灯、按钮和颜色条。
6. 环境装饰：树、灌木、石块和花坛，位置必须对应参考图。
7. 最终检查：删除漂浮、穿插、重复和无功能外挂件。

每完成一个阶段导出一张正面、45 度和侧面截图，与说明书对应阶段比对。

## 4. 乐高颗粒标准

- 所有砖块边缘使用小倒角，避免无限尖锐的 CAD 外观。
- 颗粒凸点直径、间距和高度统一，不能用随机尺寸代替。
- 砖块颜色按功能分组：主体白/米色，结构灰色，警示橙/红色，玻璃蓝色，植被绿色。
- 需要表现拼装关系时使用真实分件；只影响颜色的细线使用材质或浅浮雕。
- 不为追求细节加入参考图不存在的设备。

## 5. 材质与颜色

使用 Principled BSDF，所有材质必须通过节点导出：

- 颗粒塑料：Metallic 0，Roughness 0.55–0.75。
- 玻璃/透明蓝件：Metallic 0，Roughness 0.15–0.30，Alpha 仅在确有透明效果时使用。
- 金属设备：Metallic 0.25–0.55，Roughness 0.35–0.55。
- 颜色以参考图取样为准，记录每个主材质的 HEX 或线性 RGB。
- 不依赖 Blender 的 `diffuse_color`，必须设置 Principled BSDF 的 Base Color，否则 GLB 可能变成白模。

## 6. 相机与渲染

- 使用固定正交或低透视相机，保持与效果图同一视角。
- 默认先用 45 度斜视：方位角约 45 度，俯角约 30–35 度；最终以参考图边线平行关系校准。
- 相机焦距、正交缩放、目标点和模型旋转写入版本记录。
- 使用柔和主光、弱填充光和轻微环境光；阴影不能遮挡关键部件。
- 预览截图必须包含完整底座，模型占画布高度约 70–80%。

## 7. 还原度验收

按以下顺序验收，任一关键项失败都不能标记完成：

1. 轮廓：缩小到缩略图后，整体轮廓仍与参考图一致。
2. 比例：底座、主体、屋顶和最高设备的宽高比误差不超过 5%。
3. 部件：说明书列出的主要部件全部存在，位置误差不超过 0.5u。
4. 颜色：主体色块面积和相对位置一致，主色偏差不超过可见一档。
5. 结构：门窗、支柱、叶轮、设备与主体有真实连接，不漂浮、不穿插。
6. 视角：用同一相机截图叠加比较，关键边界偏差不超过 3%。
7. 游戏适配：GLB 在 Three.js 中方向正确、材质完整、尺寸适合目标格子。

## 8. 交付文件

每个资产至少交付：

- `asset_name.blend`
- `asset_name.glb`
- `asset_name_preview.png`
- `asset_name_spec.json`：尺寸、原点、材质、相机和版本
- 阶段截图或装配说明对照图

GLB 导出必须使用选中对象、应用缩放、保留材质节点，并在浏览器预览中验证。
