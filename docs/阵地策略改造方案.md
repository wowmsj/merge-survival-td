# 阵地策略改造方案

## 目标

在不推翻现有「方格领地 + 白天二合 + 夜间尸潮」循环的前提下，让路线、建筑位置、电力和敌人克制共同构成阵地策略。

## 现有基础

- 13x13 基地、前哨扩张、墙体与陷阱。
- 风力供电，夜战优先保障防御塔。
- 四方向随天数逐步开放。
- 普通、快速、坦克、自爆、精英、Boss、飞行、钻地共八类敌人。
- 箭塔、炮塔、电磁塔、冰冻塔，以及英雄协防。
- 白天合成、订单、蓝图解锁、夜间波次掉落。

## 核心循环

```text
白天合成 / 完成订单
        ↓
金币、蓝图、低级材料
        ↓
前哨扩张领地 + 建造阵地网络
        ↓
夜晚预告敌人组成与进攻方向
        ↓
布置路线、火力、供电、维修
        ↓
守夜获得掉落，解锁下一轮合成与扩张
```

每天的核心选择：

- 先用前哨扩大领地，还是先补火力。
- 电力给防御塔，还是给医疗站、工坊等经济建筑。
- 用墙拉长行进路线，还是留下空间布置更多火力。
- 根据夜战预告补范围、控制、对空或破甲。
- 将合成物提交订单换金币，还是保留为建筑蓝图和升级资源。

## 1. 让迷宫实际生效

当前基地已经有寻路和“不可封死最后通路”的基础。夜战地面敌人改为使用四方向的 `findPathToCore()`，并在建墙、拆墙、墙体被摧毁后重新计算路径。

- 墙体仅能放在摆下后仍有至少一个边缘入口可通向核心的位置。
- 夜战预告显示进攻方向、最短路线长度、飞行/钻地/自爆等特性。
- 路线越长，减速、范围伤害、地刺的价值越高。

规则包装：基地核心的诱导信号会将地面感染者导向预设杀伤走廊。若完全封闭，信号失控，尸群会从薄弱墙体强拆突入。飞行和钻地敌人不受地面走廊限制。

## 2. 防御塔职责

先保留现有四座塔，只补齐各自行为，避免增加大量内容却没有组合。

| 建筑 | 职责 | 克制目标 |
|---|---|---|
| 箭塔 | 高射速单体，可优先攻击飞行和快速敌人 | 快速、飞行、漏网 |
| 炮塔 | 命中后 1 格范围爆炸，低攻速 | 密集普通怪、自爆怪 |
| 电磁塔 | 连锁 3-5 个敌人，连锁伤害递减 | 成群敌人、高防敌人 |
| 冰冻塔 | 范围减速，优先主路径前方目标 | 坦克、Boss、长路线控场 |

标准阵地结构：

```text
入口地刺 / 减速沼泽
        ↓
冰冻塔拖延
        ↓
炮塔与电磁塔清群
        ↓
箭塔处理飞行与漏网
        ↓
核心附近的英雄与保底火力
```

## 3. 敌人作为战术考题

不急于新增敌人，先强化现有八种敌人的区别。

| 敌人 | 需要玩家解决的问题 |
|---|---|
| 普通 | 基础持续火力是否足够 |
| 快速 | 是否有减速与靠近核心的补漏火力 |
| 坦克 | 是否有破甲、持续伤害与石墙 |
| 自爆 | 是否将墙体和重要建筑过度堆叠 |
| 精英 | 是否有足够集火火力和石墙应对 |
| Boss | 是否准备了长路线、控制和爆发窗口 |
| 飞行 | 是否有箭塔或专门的对空覆盖 |
| 钻地 | 是否有雷达提前显形，否则它会绕过外线 |

每种敌人在夜战预告中都应有图标与一句特性标签，让玩家在入夜前能作出决策。

## 4. 支撑建筑与阵地网络

保留已有风电、医疗站、仓库、工坊、收集站、前哨站；第一阶段新增三种支撑建筑。

| 建筑 | 覆盖规则 | 作用 |
|---|---|---|
| 弹药库 | 周围 2 格 | 相邻防御塔攻速 +25%，夜战优先供电 |
| 雷达站 | 周围 3 格 | 相邻箭塔获得对空优先；范围内钻地敌人提前现身 |
| 维修站 | 周围 2 格 | 天亮后自动修复附近墙和塔，消耗废料 |

已有建筑定位调整：

- 风力发电站：稳定基础电力，不消耗燃料。
- 柴油发电机：后期探索材料合成，仅夜战消耗燃料，提供应急电力。
- 前哨站：只能建在已占领区域边缘，扩张周围 3x3。
- 仓库：后续扩展药品、废料、燃料上限。
- 工坊：产废料，支撑维修、柴油机和陷阱维护。
- 收集站：持续把低级合成材料送入棋盘，维持二合循环。

## 5. 建造规则

- 防御塔：可放在任意已占领空格，核心格除外。
- 墙、地刺、地雷、沼泽：可放在已占领空格；墙体仍必须保留地面通路。
- 资源与支撑建筑：可放在任意已占领空格，和火力建筑竞争空间。
- 前哨：仅限已占领区域边缘。
- 核心周围 2 格：适合作为英雄、维修、医疗、箭塔的最后防线。

这会自然形成前线走廊、后方经济、核心保底三层阵地，而不依赖强制内外圈限制。

## 6. 分期实施

### 第一期：让策略成立

1. 地面敌人接入 A* 四方向寻路。
2. 墙体保留最后通路。
3. 炮塔增加范围伤害，电磁塔增加连锁伤害。
4. 夜战预告增加路线长度与敌人特性。
5. 防御塔放置范围改为全部已占领领地。

### 第二期：阵地组合

1. 增加弹药库、雷达站、维修站。
2. 飞行/钻地敌人与箭塔、雷达建立明确克制。
3. 自爆敌人加入主动破墙行为。
4. 夜间电力优先级调整为核心防御支撑建筑、塔、资源建筑。

### 第三期：长线目标

1. 增加柴油发电机与夜战燃料。
2. 前哨扩张后出现高价值地块或废墟遗迹。
3. Boss 夜提供高级蓝图链和柴油机材料。
4. 多方向入口逐步开放，阵地从单线走廊演化为多线防守。

## 实施优先级

先完成第一期。它只补足已有配置和系统之间的关系，不需要新增大量画面表现，但能显著提高路线编辑、建造位置和夜战预告的策略价值。
