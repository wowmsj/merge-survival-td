# 中英文版本与设置面板

## 目标

游戏提供完整中文与英文版本，用于海外发布测试。玩家可从右上角设置按钮切换语言；语言选择与当前存档一起保存。设置面板同时收纳“重新开始”，保留二次确认以防误删存档。

## 边界

翻译所有玩家可见文字：HUD、任务、物品、建筑、英雄、敌人、引导、Toast、基地与夜战界面、剧情对白、按钮和弹窗。数值配置、物品 ID、掉落、任务规则和剧情触发规则不复制也不改动。

## 数据与接口

- 新增 `src/core/i18n/zh-CN.ts` 与 `src/core/i18n/en.ts`，键结构一致。
- 文本按稳定 ID 或语义 key 保存：`props[id]`、`buildings[id]`、`heroes[key]`、`zombies[id]`、`story[beatId]` 与 `ui[key]`。
- 新增轻量 `t(key, params?)` 和按 ID 取显示名的方法。缺失英文键回退中文，避免上线时出现空白文本。
- 现有配置仍是唯一的玩法数据来源；UI 与剧情显示层改为通过本地化接口取名称/对白。

## 存档与切换

- `IGameState` 增加 `language: 'zh-CN' | 'en'`。
- 旧存档缺少该字段时补为 `zh-CN`，不改变既有玩家的显示语言。
- 新存档按浏览器语言设置默认值：中文浏览器为 `zh-CN`，其他语言为 `en`。
- 玩家切换语言后立即保存，并以当前状态重建 Phaser 场景；不重置棋盘、任务或基地进度。

## 设置面板

- `GameScene` 右上角增加齿轮按钮。
- 打开紧凑面板，提供“中文”“English”和“重新开始”。
- 选择当前语言时关闭面板；选择另一种语言时保存并重建当前场景。
- “重新开始”先变为确认状态，3 秒内再次点击才清除存档并刷新页面；超时恢复原文案。
- 设置面板打开时阻止棋盘输入，并在关闭或切换场景时销毁自身。

## 验证

- 在 `scripts/smoke.ts` 校验两种语言均覆盖所有物品、建筑、英雄、敌人与剧情 beat。
- 校验旧存档加载后仍为中文，语言修改后能被读回。
- 运行 `npm.cmd run smoke` 与 `npm.cmd run build`。
- 在浏览器手测中文与英文下的主场景、基地、夜战、剧情、任务、背包和重开确认。

## 非目标

- 本次不增加更多语言、翻译管理后台、远程语言包下载或自动机器翻译。
- 本次不修改玩法数据和存档版本号。
