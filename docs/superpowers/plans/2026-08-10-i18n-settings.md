# 中英文版本与设置面板 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Provide complete Chinese and English game text, a persistent language setting, and a settings panel containing language controls and restart.

**Architecture:** Keep gameplay JSON as the sole source of numeric rules and identifiers. Add one small i18n facade over two same-shaped language datasets; all visible names and messages resolve through it. Store the selected language on `IGameState`; when selection changes, save and restart the current Phaser scene with the same state.

**Tech Stack:** TypeScript 5, Phaser 4, JSON configuration, browser localStorage, existing `scripts/smoke.ts` assertions.

- [ ] **Step 3: Create the contract and minimum resolver**

```ts
export type Language = 'zh-CN' | 'en';
export type LocaleData = { ui: Record<string, string>; props: Record<number, string>; buildings: Record<number, string>; heroes: Record<string, string>; zombies: Record<number, string>; story: Record<number, { who: string; text: string }[]> };

let activeLanguage: Language = 'zh-CN';
export function setLanguage(language: Language): void { activeLanguage = language; }
export function getText(key: string, params: Record<string, string | number> = {}): string {
  const value = (activeLanguage === 'en' ? en : zhCN).ui[key] ?? zhCN.ui[key] ?? key;
  return value.replace(/\{(\w+)\}/g, (_, name) => String(params[name] ?? `{${name}}`));
}
```

Use `String.replace(/\{(\w+)\}/g, ...)` for interpolation. `getText` must return the Chinese fallback before returning the key so missing English text never creates blank UI.
